Scrollable notes

This panel owns its scrolling. Gesture navigation only begins on an explicit rail, so normal content behavior stays intact.

Each row remembers a separate horizontal position. Moving away and returning restores the desktop previously selected in that row.

A direct jump to another row silently aligns that hidden row first, then performs only the vertical transition.

The demo has different numbers of desktops per row to prove that the engine is not based on a fixed three-by-three matrix.
